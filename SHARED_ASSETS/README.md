# Shared TDE visual assets

Ανεξάρτητα κοινόχρηστα γραφικά για επαναχρησιμοποίηση σε μελλοντικά έργα.

- `police_emblem.png` — το ακριβές εγκεκριμένο έμβλημα της Ελληνικής Αστυνομίας.
- `greece_map.svg` — ο ακριβής εγκεκριμένος χάρτης/υδατογράφημα Ελλάδας.

Τα δύο αρχεία είναι **standalone assets**. Δεν ανήκουν σε συγκεκριμένη εφαρμογή ή έκδοση και δεν ενσωματώνονται αυτόματα σε κανένα πρόγραμμα.

Δεν πρέπει να ξανασχεδιάζονται, να αλλάζουν χρώματα ή να αντικαθίστανται χωρίς ρητή οδηγία.

Δεν έχει εντοπιστεί ξεχωριστό εγκεκριμένο αρχείο ελληνικής σημαίας στο τρέχον GitHub. Αν προστεθεί στο μέλλον, θα αποθηκευτεί εδώ ως ξεχωριστό asset.
