# Shared TDE visual assets

Αυτός ο φάκελος περιέχει κοινόχρηστα γραφικά αρχεία για μελλοντική επαναχρησιμοποίηση.

- `police_emblem_user.png.b64` — το ακριβές εγκεκριμένο έμβλημα της Ελληνικής Αστυνομίας σε Base64 PNG.
- `skin_greece.svg` — ο ακριβής χάρτης/υδατογράφημα Ελλάδας που έχει εγκριθεί οπτικά.

Τα αρχεία αυτά είναι **ανεξάρτητα από οποιαδήποτε εφαρμογή ή έκδοση**. Δεν αποτελούν source κάποιας εφαρμογής και δεν πρέπει να ενσωματώνονται ή να τροποποιούνται χωρίς ρητή οδηγία.

Αν στο μέλλον προστεθεί ξεχωριστό αρχείο ελληνικής σημαίας, θα αποθηκευτεί εδώ ως τρίτο ανεξάρτητο asset.
