### Τι διορθώθηκε στα εργαλεία επαλήθευσης

1. Το παλιό snapshot εργαλείο αποτύγχανε κατά τη διαγραφή προσωρινής SQLite με `WinError 32`, ακόμη και με το αρχικό source. Διατηρήθηκε το traceback της αναπαραγωγής και διορθώθηκε ο καθαρισμός του fixture, χωρίς αλλαγή της εφαρμογής.
2. Στο run `38963995647` ο driver δεν εντόπιζε το owned Qt dialog «Έναρξη Βάρδιας» ως top-level UIA παράθυρο. Η αναζήτηση μέσω native HWND επέτρεψε τη δημιουργία βάρδιας στο επόμενο run.
3. Το ήδη υπάρχον κατά την παύση run `38964761440` απέτυχε αργότερα στην πλοήγηση: τα αποκλειστικά checkable κουμπιά Qt εκτίθενται από τα Windows ως `RadioButton`, ενώ ο driver φιλτράριζε μόνο `Button`. Το UI diagnostics JSON και το screenshot έδειξαν την ακριβή αιτία. Στη συνέχιση τροποποιήθηκε μόνο αυτό το φίλτρο, με διατήρηση ακριβούς τίτλου και απαίτησης ενός μοναδικού ορατού στοιχείου.
4. Το τελικό run `39011345277` πέρασε ολόκληρη τη native ροή. Κανένα αρχείο της εφαρμογής δεν άλλαξε κατά αυτές τις διορθώσεις του harness.
