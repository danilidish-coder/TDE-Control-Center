## Στάδιο Β1 — πραγματικοί χρόνοι

Ολοκληρώθηκαν 8 στοχευμένα regressions πραγματικής παραγωγής DOCX/ΒΑΣ/XLSX: 27 λεπτά, μεσάνυχτα, αλλαγή έτους και 29 ώρες, 8 ώρες 37 λεπτά, ίδια καταγεγραμμένη στιγμή, επανεκκίνηση/επαναπαραγωγή έναν χρόνο αργότερα, ενεργή προεπισκόπηση και πραγματικό ρολόι βάσης. Το βασικό schema και οι timestamps δεν άλλαξαν. Προστέθηκε ένδειξη ενεργής βάρδιας στα υπάρχοντα πεδία υπογραφής, χωρίς επεξεργασία προτύπων. Απορρίπτεται λήξη πριν από έναρξη αντί να επινοείται ώρα. Το παλιό API χωρίς πραγματικές ώρες δεν δημιουργεί υποθετική βάρδια 10:00/24h.

Απόφαση χρήστη: η autonomous εξετάζεται σε χωριστή επόμενη εργασία και παραμένει ανέπαφη. Για άγνωστο/απομακρυσμένο ιδιοκτήτη lock εγκρίθηκε προστασία δεδομένων και διαχειριστική επιβεβαίωση αντί αυτόματης αφαίρεσης.
