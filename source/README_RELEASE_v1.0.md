# TDE Control Center — Έκδοση 1.0

Τελική έκδοση του Κέντρου Ελέγχου Τ.Δ.Ε. Κρυσταλλοπηγής.

## Αποθήκευση
Η εφαρμογή χρησιμοποιεί τον κρυφό φάκελο .tde_runtime δίπλα στο EXE.
Ο φάκελος περιέχει τη βάση δεδομένων και τα αρχειοθετημένα Word/Excel.
Σε αναβάθμιση αλλάζει μόνο το EXE. Σε μεταφορά αντιγράφονται μαζί το EXE
και ολόκληρος ο .tde_runtime.

## Build
Χρησιμοποιείται το TDE_CONTROL_CENTER_v1.0.spec.
